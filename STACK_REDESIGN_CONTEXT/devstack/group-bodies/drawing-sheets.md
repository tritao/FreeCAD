# Semantic BIM drawing sheets

Add drawing sheets as consumers of the same renderer-neutral BIM
representations used by contextual model views. The layers cover sheet
identity and publishing, layout workflows, stable TechDraw annotations,
material-aware cut graphics, canonical joined plan contours, reliable view
transitions, and semantic linework ownership.

Architectural invariant:

> Viewport rendering, snapping, editing, and drawing output share canonical
> BIM geometry instead of reconstructing architectural topology per renderer.
